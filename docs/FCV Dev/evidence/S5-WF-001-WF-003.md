## Riesgos residuales

- Túnel público temporal: mientras está abierto, la API local es accesible desde Internet (protegida por JWT). Su URL cambia en cada arranque, así que los workflows programados no deben publicarse apuntando a un túnel efímero.
- El JWT del ADMIN viaja en la ejecución. Se configuró `saveDataSuccessExecution: none`, pero las ejecuciones manuales y las fallidas sí se guardan en la instancia compartida.
- La deduplicación usa el almacén del nodo `Remove Duplicates` (historial de 10 000 claves).
